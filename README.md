IntelliBot - Rule Based AI Chatbot

## Project Overview

IntelliBot is a simple Rule-Based AI Chatbot developed using Python. It responds to predefined user inputs using decision-making logic and dictionary-based response mapping.

This project was created as part of an Artificial Intelligence Internship to understand the fundamentals of chatbot development, control flow, and human-computer interaction.

---

## Features

* Handles greetings such as Hi, Hello, and Hey
* Answers basic AI-related questions
* Responds to predefined user inputs
* Provides help commands
* Supports exit commands (bye, exit, quit)
* Uses dictionary-based response lookup
* Runs in a continuous chat loop

---

## Technologies Used

* Python 3
* Dictionaries (Hash Maps)
* Functions
* Loops
* Conditional Statements
